# biaoqing-yanyi · 表情演绎

写中文 AI 视频**表演类**提示词的技能：微表情、情绪台词、眼神、口型、呼吸、体态、语气节奏、隐忍哭戏、发怒、撒娇、一句话多变体、时间码表演拆解。

纯 Markdown，无依赖。适用于 Seedance / Kling / Hailuo / Veo / Sora 等一切支持图生视频或文生视频的工具。

## 核心思路

```text
人格气质 → 表达态度 → 情绪波 → 语气节奏 → 身体动作 → 画面参数
```

**画面是结果，人物动机、关系位置和情绪结构才是源头。** 每一句台词都是一次关系动作，不是一段文字。

最常见的失败写法是只给一个情绪标签（"她很难过"），让模型自己猜表演。这个技能要做的是把情绪翻译成**看得见、听得见的变化**：眼皮、呼吸、下颌、肩线、尾音。

## 六层构建法

写时间码之前，先定这六层：

| 层 | 要回答的问题 |
| --- | --- |
| 1. 人格气质 | 这是一个什么样的人在演？平时怎么控制情绪？ |
| 2. 表达态度 | 这句话是说给谁听的？是请求、试探、指责、服软、调情、拒绝、告别还是自我保护？ |
| 3. 情绪波 | 藏 → 微漏 → 收回 → 再漏 → 峰值 → 余味 |
| 4. 语气节奏 | 哪个字压低、哪个字放轻、哪里停、哪里吸气、哪里是情绪呼吸点、尾音是收住还是拖住 |
| 5. 身体动作 | 只允许小动作：垂眼、抬眼、偏头、抿唇、捏袖口、收紧肩膀、微微前倾 |
| 6. 画面参数 | 9:16、固定机位、景别、光线、背景、真实感、身份连续性、负面限制 |

关键一问：**这句台词是说给谁听的？**

台词的字面意思不重要，重要的是——哪些词必须压低，哪些词必须轻，哪些词不能带问号语气，尾音是收、拖、颤、软还是落。

```text
低频 = 稳、克制、压抑、控制
高频 = 情绪微微上扬、撒娇、委屈、着急
停顿 = 思考、犹豫、自我控制、没说出口的话
吸气点 = 情绪泄漏的地方
```

## 标准演绎基底（可直接复用）

```text

稳定机位，面部/颈部/上半身动作清晰，真实皮肤质感，真实眼球运动，真实呼吸，细微微表情。
```

## 时间码写法

**6 秒**

| 区间 | 任务 |
| --- | --- |
| 0-1s | 保持第一层情绪面具，眼、唇、肩、呼吸全部收住 |
| 1-2s | 情绪通过注视、眼皮、呼吸、下颌或嘴角开始上浮 |
| 2-3s | 身体轻微反应：头部角度、重心、手或肩膀变化 |
| 3-5s | 说台词，按设计好的语气节奏和情绪色彩 |
| 5-6s | 余味：情绪变冷、断裂、变硬、退回或软化 |

**15 秒**

| 区间 | 任务 |
| --- | --- |
| 0-2s | 建立姿态、注视、呼吸、关系态度和隐藏状态 |
| 2-4s | 眼/头/嘴第一次小幅变化，情绪泄漏但仍在控制 |
| 4-6s | 怀疑、心疼、怒意、温柔、俏皮或委屈变得可见 |
| 6-8s | 情绪加深、退开或改变方向 |
| 8-10s | 自我控制、自嘲、尴尬、恢复或软化 |
| 10-12s | 回望光/人/镜头；受控的情绪回归 |
| 12-15s | 保持最终注视与余味；无黑屏、无转场（除非要求） |

## 情绪公式（节选）

### 哭前坦白

```text
受伤 → 抵赖 → 找借口 → 强笑 → 情绪反扑 → 整理体面 → 说真话
```

眼眶红但努力笑 · 前半段避开直视 · 呼吸发抖或卡住 · 嘴角憋住 · 顺手抹平衣角维持体面 · **真话比借口说得更低更轻**。

### 隐忍哭诉

室内自然光，固定中近景，一镜到底。0-2s 垂头收住 → 2-4s 抬一点头但视线仍向下 → 4-6s 第一次发问带哭腔但不喊 → 6-8s 肩膀绷紧、无助感上升 → 8-11s 峰值：小幅前倾、嘴唇颤、指控受控、尾音发抖 → 11-13s 说完，重呼吸、眼神空 → 13-15s 平复，必要时轻擦眼泪，**不要过演**。

### 温柔关切 / 古装回望

低头浅笑 → 笑意淡去、视线右移 → 担忧与疑问进眼睛、唇微启欲言又止 → 视线下沉、垂头、平静的难过（不哭） → 轻闭眼、恢复呼吸、藏起来的自嘲笑 → 抬头看向柔光、受控的明亮回归、嘴角含委屈 → 定格注视，安静、微凉、微怅。

### 女朋友撒娇

```text
假装平静 → 小期待 → 软委屈 → 俏皮请求 → 等回应
```

不像小孩、不卡通可爱 · **眼睛先软，嘴角后笑** · 头可以偏但不要过分 · 声音轻软、尾音可轻拖 · 身体微前倾或肩膀轻缩 · 手可以摸袖口/抱枕/杯沿/桌边。

示例台词「你就陪我一会儿嘛。」：「你就」轻而试探，「陪我」更暖更近，「一会儿嘛」尾音轻拖带小尾音，**不鼻音、不夸张**。

## 一句话多变体

同一条台词（如「你有病啊」「滚」），固定基底，只改**情绪动机 + 眼睛 + 嘴 + 身体 + 语气节奏 + 余味**：

| 变体 | 关键差别 |
| --- | --- |
| 生气 | 不是立刻大喊。怒气先压进眼睛，再往上顶，最后从台词里扔出来 |
| 气笑 | 不是大笑。是荒谬、不信和轻讥讽；眼先不信，嘴角后抬 |
| 厌恶 | 不是暴怒也不是喜剧。轻微后仰、眯眼、嘴部动作极小、视线排斥、语气更冷 |
| 撒娇 | 声音更软、眼神更轻、小幅偏头、笑意小、压力小；自然，不幼稚 |
| 委屈 | 眼睛湿、视线低、嘴唇压了再松、呼吸小结、音量更小、停顿更有克制 |
| 冷淡告别 | 情绪已过峰值。静止、眼皮低垂、嘴部动作极小、低频、干净的停顿，最后一个不索要回应的注视 |

## 出手前检查清单

- 时间区间加起来等于要求时长
- 台词有明确的听者和关系目的
- **人格气质出现在面部细节之前**
- 每一个情绪节拍都改变了某个看得见或听得见的东西
- 眼神路径写清楚：看哪里、何时避开、何时回望
- 嘴部细节包含嘴角、唇线、张口幅度、尾音
- 语气写明重音、轻音、呼吸、音高、停顿、情绪呼吸点
- 身体动作小到足以让 AI 视频真实执行
- 负面提示挡住脸崩、过演、多人物、字幕、水印

## 安装与用法

把 `SKILL.md` 与 `agents/` 一起放进宿主技能目录，或在对话里直接载入 `SKILL.md`。

```text
写一条 6 秒隐忍哭诉的表演提示词，9:16 固定机位，台词「我没哭，只是有点累」
帮我把「你有病啊」写成 6 个不同情绪变体，同一个基底
这条 15 秒的温柔关切拆成时间码，声音结构写细一点
```

## 边界

不保证一次出片、不承诺特定平台兼容性、不替代演员与导演判断。
台词的情绪设计是结构建议，不是唯一解法；用户明确的要求永远优先于本技能的默认。
